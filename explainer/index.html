    1. Карта проекта

    Путь данных от API hh.ru до графика. Нажмите на блок, чтобы узнать, что он делает, какой файл за него отвечает и какой вопрос решает. Кнопка ниже проводит одну вакансию через всю систему.

    Анимация покажет, как меняется одна вакансия на каждом шаге.

    Выберите блок на схеме.

    2. Как думать над задачей

    От бизнес-вопроса к решению. Каждый шаг: вопрос → рассуждение → решение → что проверить. Внизу — типичные ошибки новичков.

    3. Требования

    User story отвечает на «кто, что и зачем». Критерии приёмки — на «как проверить, что сделано». Use case описывает шаги и что происходит при сбое.

    4. Модель данных

    Нажмите на таблицу: появится её назначение, ключи, ограничения и почему они именно такие. Линии — внешние ключи (1 — N: одна строка слева, много справа).

    Выберите таблицу на диаграмме.

    5. ETL по шагам

    Extract → Transform → Load. Три интерактивных демонстрации: пагинация, повторы с экспоненциальной задержкой и upsert при повторном запуске.

    6. SQL, объяснённый на пальцах

    Каждый запрос разобран на маленькой таблице. Нажимайте «Следующий шаг» и смотрите, как меняются строки. Подсвеченный фрагмент SQL — то, что выполняется на этом шаге.

    9. Визуализация данных

    Графики нарисованы вручную в SVG по результатам SQL-запросов (файл data.js). Наведите курсор на элемент, чтобы увидеть точное значение.

    10. Подводные камни

    Реальные проблемы этого проекта. Для каждой: как бы её обнаружил аналитик, как проверить и что сделано. Отмеченные «встретилось» — случились во время разработки.

    Вопросы, которые вероятно зададут по проекту. Сначала ответьте сами вслух, потом раскройте ответ.
