# Итоговая сводка

## Что получилось

- **Требования** (`docs/requirements/`): цели с метриками, акторы, 8 user stories с Given/When/Then, 3 use case с альтернативными потоками, глоссарий, 10 открытых вопросов с принятыми решениями.
- **Модель данных**: 8 таблиц (`sql/001_schema.sql`), SCD2-история с частичным уникальным индексом «одна актуальная версия», функция пересчёта зарплаты в ₽ на руки, 6 ADR.
- **ETL**: `python -m src.main load --days 7` — пагинация, повторы на 429/5xx с экспоненциальной задержкой и jitter, Retry-After, таймауты, пауза между запросами, upsert по `hh_id`, одна транзакция на вакансию, журнал `load_run`. Детальная карточка скачивается только для новых или поднятых вакансий.
- **SQL**: 7 запросов на 6 вопросов. На базе в 300 тыс. вакансий два самых тяжёлых ускорены: q6 4043 → 143 мс (переписан), q5 1300 → 109 мс (индексы в `sql/002_indexes.sql`).
- **Отчёт**: 4 PNG + CSV в `reports/` с пояснением «что видно и чего не видно».
- **Сайт** `explainer/index.html`: 12 разделов, работает без сервера, проверен Playwright.
- **Тесты**: 50, все проходят.

## Что не сделано и почему

- **Реальные данные hh.ru**: API ответил 403 без токена. Работаем на фикстурах того же формата. Реальный клиент готов, включается через `.env`.
- **Docker**: на машине нет. Использован локальный PostgreSQL 16; `docker-compose.yml` написан, но не запускался.
- **SVG ER-диаграммы через mmdc**: утилиты нет. Mermaid-код в `docs/data_model.md` рендерят GitHub и редакторы; интерактивная диаграмма — на сайте.
- **Python 3.12**: на машине 3.14; несовместимого с 3.12 кода нет, но на 3.12 не запускалось.
- **Эндпоинт /api/summary**: протестирован через TestClient. Для `serve` нужен `pip install uvicorn` — не устанавливался.
- **q2 (медиана)**: 0,6 с на 300 тыс. вакансий, оставлен без оптимизации; путь — материализованное представление.

## Найденные по ходу проблемы

1. Часовой пояс сервера PostgreSQL — `Asia/Tomsk`: `::date` превращал 23:59 МСК в следующий день (упали тест и API). Везде `AT TIME ZONE 'Europe/Moscow'`.
2. psycopg 3 без autocommit превращает вложенные транзакции в SAVEPOINT — выбран autocommit + явные `conn.transaction()`.
3. Поиск «возможных дублей» без окна по времени срабатывал почти на всё — ограничен 14 днями.
4. Заложенный в данные рост зарплат +1,2 %/мес не виден на графике: шум выборок больше сигнала.
